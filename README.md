# Решение задач классификации текста при помощи языковой модели BERT с добавлением семантической информации на базе формата CoBaLD. 

Исследование посвящено влиянию обогащения семантической инфоормацией эмбеддингов моделей класса BERT (использована предобученная модель 'DeepPavlov/rubert-base-cased') на решение задач классификации текстов.

* Язык: русский
* Задачи: анализ тональности и детекция токсичности\
* Датасеты:
  * анализ тональности: [ai-forever/kinopoisk-sentiment-classification](https://huggingface.co/datasets/ai-forever/kinopoisk-sentiment-classification)
  * детекция токсичности: [blackmoon/russian-language-toxic-comments](https://www.kaggle.com/datasets/blackmoon/russian-language-toxic-comments)

## Семантическая разметка
В рамках ислледования использовалась семантическая разметка в формате CoBaLD - [CoBaLD Annotation Project](https://github.com/CobaldAnnotation). Разметка была происзведена автоматически с использованием парсера, написанного в рамках проекта CoBaLD. 
Семантическая разметка произведена по двум параметрам:\
Семантический класс (СК) – семантическое поле, в котором лежит значение слова\
Семантическая роль (СР) – глубинная позиция.

## Гипотеза
1. Обогащение предобученных эмбеддингов BERT семантической информацией, структура которой задана человеком, поможет улучшить качество решения моделью задач анализа тональности и детекции токсичности;
2. Формат разметки CoBaLD действительно отражает реальные языковые явления и пригоден для обогащения языковых моделей семантикой.

## Актуальность
Исследование может иметь практическую пользу для улучшения качества работы языковых моделей. Кроме того, исследование поможет понять, насколько семантическая разметка CoBaLD пригодна для обогащения предобученных эмбеддингов.

## Новизна
Качество работы больших языковых моделей на последние годы достигло очень высоких показателей. Однако, есть задачи, общепринятого решения которых нет до сих пор. Например, работа над дизамбигуацией значений слов (снятием омонимии) и тем, что языковые модели игнорируют отрицание. Причина этих проблем – то, как языковые модели строят эмбеддинги – числовые представления токенов. Результаты нашей работы могут стать вкладом в понимание того, может ли добавление внешней информации, формат которой определен человеком, улучшить качество представления слов в языковых моделях.

## Цель
Определить, влияет ли добавление к эмбеддингам предобученных языковых моделей семейства BERT эксплицитной семантической информации на качество выполнения задач классификации текстов.

## Структура репозитория:
1. **sentiment_baseline** - бейзлан без обогащения семантикой для задачи анализа тональности
2. **toxity_baseline** - бейзлайн для детекции токсичности
3. **sentiment_enriched** - обогащенная семантикой модель для анализа тональности
4. **toxity_enriched** - обогащенная семантикой модель для детекции токсичности
