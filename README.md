В данном репозитории размещен код для моей курсовой работы по обогащению семантической информацией эмбеддингов модели BERT для решения задач анализа тональности и детекции токсичности. Все теоретические подробности в тексте работы.

Содержание:
1. baseline1 для обеих задач - бейзлайны с использованием дефолтной модели и трейнера
2. baseline2 для обеих задач - бейзлайны с кастомной моделью и трейнлупами, но без конкатенации с семантикой. сделано для максимальной чистоты эксперимента
3. enriched_with_semantics - обогащенные семантикой модели
